Datos de actividad:

  • Historial de misiones realizadas

Datos generados durante las misiones:

  • Interacción con sitios web de terceros

3. Finalidad del tratamiento

Los datos se utilizan para:

  • Crear y gestionar la cuenta del usuario
  • Asignar misiones de investigación de mercado
  • Validar la correcta ejecución de las misiones
  • Gestionar recompensas
  • Prevenir fraude
  • Generar informes de mercado anonimizados

4. Base legal del tratamiento (Art. 6 RGPD)

El tratamiento se basa en:

  • En el consentimeinto para el correcto uso de la plataforma
  • Consentimiento del usuario (uso de la extensión y recogida de datos durante misiones)
  • Interés legítimo (seguridad, prevención de fraude y mejora del servicio)

5. Uso de la extensión de navegador

Para participar en las misiones, el usuario debe instalar una extensión de navegador que permite:

  • Guiar la ejecución de las misiones
  • Recopilar datos durante la navegación en las misiones asignadas

La recopilación de datos:

  • Se limita exclusivamente a la ejecución de misiones activas
  • No se realiza fuera de dichas misiones
  • Requiere aceptación expresa del usuario

6. Conservación de datos

Los datos se conservarán:

  • Mientras la cuenta permanezca activa
  • Durante el tiempo necesario para cumplir obligaciones legales
  • Hasta que el usuario solicite su eliminación o rectificación

7. Cesión de datos

Los datos podrán compartirse con:

  • Clientes de investigación de mercado (únicamente de forma anonimizada o agregada)
  • Proveedores tecnológicos necesarios para operar la plataforma
  • Autoridades públicas cuando sea legalmente requerido
